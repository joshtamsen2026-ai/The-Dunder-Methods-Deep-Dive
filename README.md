# Library Management System

Overview
The Library Management System is a Python-based application that demonstrates object-oriented programming principles including:

Classes and Objects
Inheritance
Encapsulation
Method Overriding
Properties
Data Validation
File Export Operations
The system allows users to manage both physical books and ebooks, perform searches, track availability, generate summaries, and export a professional CSV report.

Features
Book Management
Add physical books to the catalog
Validate publication year
Check books in and out
Track availability status
EBook Management
Inherits functionality from the Book class
Supports multiple simultaneous users
Tracks active checkout count
Stores ebook file size information
Search Capabilities
Search books by title
Search books by author
Case-insensitive matching
Catalog Reporting
Display inventory summaries
Calculate catalog statistics
Track availability metrics
Generate professional CSV reports
Automated CSV Export
The system automatically exports a detailed report containing:

Executive Summary
Inventory Statistics
Availability Information
Book Metadata
EBook Usage Metrics
Export Timestamp
The report is automatically opened after creation.

Example Usage
Creating a Catalog
catalog = Catalog()
Adding Books
catalog.add_book(
    Book(
        "Python Crash Course",
        "Eric Matthes",
        2019
    )
)

catalog.add_book(
    EBook(
        "AI Engineering",
        "Chip Huyen",
        2025,
        15.2
    )
)
Searching by Title
results = catalog.search_by_title("python")
print(results)
Searching by Author
results = catalog.search_by_author("Martin")
print(results)
Checking Out a Book
catalog.books[0].check_out()
Checking Out an EBook
ebook = catalog.books[-1]

ebook.check_out()
ebook.check_out()
ebook.check_out()
Exporting the Report
catalog.export_to_csv()
